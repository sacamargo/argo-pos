|------|---------|--------|
| 1 | Core MVP operable | En curso / cierre |

## Core MVP (Fase 1) — checklist

- [x] Auth + roles `master` / `admin` / `cashier`
- [x] Dashboard vía AnalyticsService (método de pago en últimas ventas)
- [x] POS + calculadora de cambio en efectivo
- [x] Historial y detalle de ventas + anulación
- [x] Catálogo: alta de producto/variantes + cambio de precio
- [x] Inventario: entradas, ajustes, alta de ingredientes
- [x] Gestión de usuarios (master)
